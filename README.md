## Proyectos principales

- [Stomalyzer](https://github.com/godkiun/stomalyzer): Dispositivo biomédico portátil para diagnóstico de SIBO mediante la medición continua de hidrógeno (H2) y metano (CH4). Cuenta con firmware en C/C++ sobre PIC18F45K50, API REST en FastAPI, base de datos en Supabase (PostgreSQL), regresión en Scikit-Learn y despliegue en contenedores Docker.
- [VOLTLYZER-LC](https://github.com/godkiun/VOLTLYZER-LC): Sistema de monitoreo y predicción de interrupciones eléctricas locales. Combina un frontend en Next.js/TypeScript, scraping automático de datos climáticos en Flask/BeautifulSoup y un clasificador Random Forest.
- [PNEUDIX ONE](https://github.com/godkiun): Estación didáctica electroneumática diseñada en SolidWorks para laboratorios de mecatrónica, con lógica de control estructurada en PLCs Siemens (TIA Portal / IEC 61131-3), validación en MATLAB y simulación en FluidSIM (norma ISO 1219). Destacado en el certamen INNOVATEC.
